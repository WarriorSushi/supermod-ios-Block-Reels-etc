# Supermod mascot artwork

The approved `Supermod-approved-icon-original.png` remains the source for the app icon. `SupermodIcon.icon` contains separate mascot and backdrop artwork for Icon Composer. Its two layers also appear in the SwiftUI launch transition.

The original two in-app poses were created with the built-in image generation tool using the approved cat as the identity reference. Both images retain transparency.

- [Home pose](../Supermod/Resources/Assets.xcassets/MascotHome.imageset/mascot.png). “Transparent background asset for a premium iOS app home hero. Reference is the exact character identity: cream porcelain 3D cat, dark angular black sunglasses with restrained coral reflections, coral hoodie, same ears, head, cheeks and 2 whiskers each side. Render the same character in a new half-body pose, casually leaning an elbow on an invisible ledge, looking toward the left, warm, self assured. Render from chest up; all edges and ears in frame; asset positioned centered so it can be composed at the right of a card. High-end sculpted toy, soft studio key, crisp edge. No black background, no tile, no floor shadow, no prop, no UI, no text. True alpha around character.”
- [Onboarding pose](../Supermod/Resources/Assets.xcassets/MascotRest.imageset/mascot.png). “Transparent background asset for a premium iOS app onboarding. Reference exact character identity: cream porcelain 3D cat, angular black sunglasses, sculptural coral hoodie, same face and whiskers. Same character sitting calmly in a relaxed pose with paws on knees, sunglasses on, calm and playful. Full character including ears and paws in frame, compact balanced silhouette, front three-quarter view. Premium soft studio lighting, no tile, no floor shadow, no text, no accessories, true alpha around the character.”

- [Timer pose](../Supermod/Resources/Assets.xcassets/MascotTimer.imageset/mascot.png), generated with the built-in image tool using the Home and Rest poses as identity references. Prompt: “Same cream porcelain cat, angular sunglasses and coral hoodie, peering with mock seriousness over a peach kitchen timer. One paw holds it while the other is about to boop its top button. Soft studio lighting, complete half-body cutout, true alpha, and no text or background.”
