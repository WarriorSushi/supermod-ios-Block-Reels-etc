# Supermod — Codex handoff

This package contains a build prompt and private design references, **not an app prototype**.

## Use
Open your intended project folder in Codex. Add this folder to the workspace and paste the contents of `SUPERMOD_CODEX_PROMPT.md` into Codex. The prompt is self-contained; the references provide visual support. The original video is optional and is not included in this ZIP.

## Reference limits
The source is the user-supplied `screen-recording-of-onboarding-sociallite.MP4` (230.94 seconds). The included frames are downscaled study references with approximate timestamps. No account-chooser frames are included. Do not publish or bundle competitor screenshots in Supermod.

The recording ends at the paywall. It does not demonstrate the logged-in app interior or validate filters. The prompt explicitly distinguishes observations, proposed design, and pending live-account checks.

## Decisions retained
Instagram-first; native iOS; long SocialLite-inspired onboarding; user-selected mods before opening Instagram; optional stricter in-app mode; system/light/dark appearance; core functionality before extra media features; local statistics; future-ready account boundaries; no custom backend; original premium dimensional icon; simulator-first implementation.

## Provisional decisions
Shared-Reel behavior uses a documented fallback because question 4 received an unlisted option. The home screen and in-app controls are authored proposals because they were not shown in the video. Recorded Indian prices are simulator-only seed values, not approved launch prices.

## Review boundary
The public technical references are in `SOURCES.md`. The brief is not a guarantee of live Instagram compatibility or App Store acceptance. Physical-device and authenticated-platform checks remain pending.
