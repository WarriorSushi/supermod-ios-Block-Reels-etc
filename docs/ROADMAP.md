# Project status and roadmap

Supermod is an experimental source release. This is a set of priorities, not a shipping schedule.

## In this snapshot

- Embedded Instagram, Facebook and public YouTube browsing with separate sessions.
- Reversible supported filters, a Home Scroll timer and filter locking.
- Circular draggable browsing controls with a countdown ring.
- Instagram feed stability safeguards, bounded pagination recovery and Home pull-to-refresh.
- Local StoreKit, model/WebKit tests and UI walkthroughs.

## Before a public binary release

- Establish appropriate service permissions and media redistribution rights.
- Complete real-device accessibility, localization, sign-in and navigation testing.
- Validate live Apple sandbox billing, restore, expiry and disclosure behavior.
- Finish public support/privacy materials and distribution signing/review.
- Test platform changes and network failures without relying only on synthetic fixtures.

## Useful community work

- Minimal, synthetic regressions for changed site markup and localized labels.
- VoiceOver, Dynamic Type, contrast and reduced-motion improvements.
- Better loading/error feedback and simpler controls.
- Reproducible device reports that contain no private social content.

## Not implemented or promised

System-wide blocking, a Family Controls shield, Android support, background audio, YouTube account sign-in, additional social networks and a public release date.
