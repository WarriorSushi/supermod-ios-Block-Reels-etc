The navigation spring uses response 0.42 and damping 0.86, with small directional offsets and fades. Welcome uses a slower 0.78/0.74 settle after the launch overlay. These are tuned adaptations, not a claim that SwiftUI reproduces another app frame for frame. Reduce Motion removes directional travel and expansion. Dynamic Type content scrolls above the fixed action area. Full physical-device assistive acceptance remains open as described in the RC handoff.
