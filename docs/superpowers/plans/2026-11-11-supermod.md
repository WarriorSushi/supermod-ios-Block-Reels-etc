# Supermod implementation plan

- Establish the Xcode project, build and launch the native shell, and connect a persistent WebKit session to the approved Instagram host.
- Implement Codable preferences and onboarding navigation, projection, mods, usage accounting, and strict session expiry. Verify edge cases in XCTest.
- Build the 26-step flow on shared SwiftUI components with an original icon and artwork. Adapt the reference's motion and pacing.
- Implement scoped Instagram rules in a separate WebKit world. Exercise reversible filtering and same-document navigation in WebKit fixtures. Block individual Reels when Reels are hidden until isolation is verified.
- Connect verified StoreKit entitlements, local India storefront test data, sample mode, and privacy controls. Exercise purchase, restore, and revocation locally.
- Capture simulator evidence, check light and dark rendering, and document release dependencies and live account checks.

Use iOS 17+, one persistent Instagram profile, no custom server, no account sign-up, and no production transactions. Follow Supermod-Codex-Brief/SUPERMOD_CODEX_PROMPT.md.
